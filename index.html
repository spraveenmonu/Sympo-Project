Common Vulnerabilities

These are real-world security weaknesses found in websites and systems every day.

🚪

Open Ports

Leaving unnecessary ports open on a server is like leaving doors unlocked. Attackers scan for open ports to find ways in. Always close ports you don't need.

Common risky ports: 21 (FTP), 23 (Telnet), 3389 (RDP)
📡

Insecure Protocols

Using HTTP instead of HTTPS, or Telnet instead of SSH, means your data travels without encryption. Anyone on the same network can read it.

Always use: HTTPS, SSH, SFTP, TLS
🔓

Weak Passwords

Passwords like "123456", "password", or "admin" can be cracked in seconds. Use long, unique passwords with numbers and symbols.

Bad: admin123 | Good: Tr@f!c_L1ght$_42
🐛

Unpatched Software

Old software has known bugs that attackers exploit. Regular updates and patches fix these vulnerabilities before attackers can use them.

Always update: OS, browsers, plugins, apps
🎣

Phishing

Fake emails or websites that look real but steal your information. Always check the URL and sender's email address before clicking links.

Fake: g00gle.com | Real: google.com
💾

Data Exposure

Websites accidentally exposing sensitive info through HTML comments, error messages, or publicly accessible files like robots.txt.

Check: View Source, /robots.txt, Console logs

Hints & Resources

Explore these tips and resources to improve your cybersecurity knowledge.

01

Learn Browser DevTools

Press F12 in any browser to open Developer Tools. Explore the Elements, Console, Network, and Application tabs — they reveal everything about a webpage.

📖 Chrome DevTools Guide →
02

Understand Common Ports

Port 80 (HTTP), 443 (HTTPS), 22 (SSH), 21 (FTP), 25 (SMTP), 53 (DNS), 3306 (MySQL). Knowing these helps you understand network security.

📖 Port Numbers List →
03

Try Free CTF Platforms

Practice your skills on beginner-friendly platforms like TryHackMe, PicoCTF, and OverTheWire. They teach you step-by-step with guided challenges.

📖 TryHackMe →
04

Learn About OWASP Top 10

OWASP Top 10 is a list of the most critical web security risks. Understanding these helps you identify vulnerabilities in real applications.

📖 OWASP Top 10 →
05

Check robots.txt

Every website can have a robots.txt file. It tells search engines what to index, but often accidentally reveals hidden admin pages and sensitive paths.

📖 What is robots.txt? →
06

Stay Ethical!

Only test security on systems you have permission to test. Unauthorized hacking is illegal. Use your knowledge to protect, not to harm.
